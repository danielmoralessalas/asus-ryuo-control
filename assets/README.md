# Imagen del dispositivo

`ryuo-screen.png` es una imagen oficial de ASUS ROG RYUO IV SLC 360 ARGB,
descargada sin modificaciones para usarla como referencia del editor de pantalla.

- Página: https://rog.asus.com/cooling/cpu-liquid-coolers/rog-ryuo/rog-ryuo-iv-slc-360-argb/
- Imagen: https://dlcdnwebimgs.asus.com/files/media/d3b46fd8-035f-41c1-a995-2dca5a228e9b/v1/img/screen/screen.png
- Consultada: 2026-11-06.

La imagen y las marcas pertenecen a ASUS; no se incluyen bajo la licencia MIT
del código. El editor superpone los sensores en Qt, sin modificar el archivo.
